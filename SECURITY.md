# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| 0.1.x | Yes |

## Security posture

Cloud DevOps MCP Server runs locally over stdio. It does not require secrets, cloud credentials or external network access.

The current version is advisory only. It analyzes structured inputs and returns guidance. It does not deploy infrastructure, change cloud resources, write to production systems or call external APIs.

## Reporting a vulnerability

Open a private security advisory or contact Alex C. Godwin through the profile links in the repository README.

Please include:

- Affected version or commit.
- Steps to reproduce.
- Expected and actual behavior.
- Impact and suggested mitigation, if known.
